How to use
  1. Load your sheet. Drop in an .xlsx, .xls or .csv. Columns are matched for you.
  2. Pick a format. 6-up portrait, 4-up landscape, 21-up A10, or one-per-sheet A4 landscape signage.
  3. Set copies. Use the − / + next to each item. 0 skips it.
  4. Print. Scale 100%, margins None.
